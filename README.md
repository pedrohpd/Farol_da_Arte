## 🚀 Como Executar

Siga os passos abaixo para rodar o projeto localmente:

### 🎨 Frontend

1. Entre na pasta do frontend:
   ```bash
   cd frontend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie a aplicação:
   ```bash
   npm run dev
   ```
